# LUNASAFE — Sample Website Prototype

Open `index.html` in a browser.

This is a front-end sample for the AI-Based Landing Risk Assessment problem statement.
It demonstrates:
- planetary terrain visualization
- hazard markers
- candidate landing zones
- risk scores
- recommended landing zone
- AI assessment panel
- dynamic re-assessment when a new hazard is simulated

The AI/vision and risk calculations are represented as prototype UI/logic here; these should be replaced by your actual model/backend during the hackathon.
